小熊记账

使用方法
1. 双击“小熊记账.exe”。
2. 点击“记一笔”，选择收入或支出，填写金额、分类和日期后保存。
3. 月度概览会自动显示收入、支出和结余。

数据说明
- 数据保存在本机 MySQL 的 bear_accounting 数据库中。
- 首次启动会自动创建数据库和数据表，并将旧版 data\\ledger.json 导入一次。
- 本软件不联网、不登录、不上传账目。
- 启动前请确保本机 MySQL 服务已启动，默认连接 127.0.0.1:3306，账号 root。
- 连接信息保存在 data\\mysql-config.json，仅留在本机，不会提交到 GitHub。

当前版本包含：
- 收入/支出新增、编辑、删除
- 按月份、类型、分类筛选
- 月度收入、支出、结余概览
- 默认分类、自定义分类、重命名、停用/恢复
- 分类合并与历史账目迁移
- 数据库事务保存，写入失败自动回滚
- 原 data\\ledger.json 保留用于旧数据迁移；之后的账目保存在 MySQL 中，备份须备份数据库。
- 贪吃蛇小游戏：支持方向键、WASD 和屏幕方向按钮
