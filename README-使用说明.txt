小熊记账

使用方法
1. 双击“小熊记账.exe”。
2. 点击“记一笔”，选择收入或支出，填写金额、分类和日期后保存。
3. 月度概览会自动显示收入、支出和结余。

数据说明
- 数据保存在本程序同目录的 data\\ledger.json。
- 本软件不联网、不登录、不上传账目。
- 需要迁移到另一台电脑时，请整体复制“小熊记账.exe”和 data 文件夹。
- 请不要用记事本直接修改 ledger.json；如需手动备份，复制整个文件夹即可。

当前版本包含：
- 收入/支出新增、编辑、删除
- 按月份、类型、分类筛选
- 月度收入、支出、结余概览
- 默认分类、自定义分类、重命名、停用/恢复
- 分类合并与历史账目迁移
- 原子写入，减少写入中断造成的半文件风险
